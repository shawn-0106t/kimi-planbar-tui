# kimi-planbar-tui-ts — experimental, frozen

This directory holds a former TS implementation of Kimi Planbar TUI built on **Bun + OpenTUI**. It is **experimental and frozen**: kept for reference only, no longer shipped in GitHub Releases, no longer maintained (no bug fixes, no features), and it may be removed at any time — do not rely on it.

- Supported implementations: the Rust edition in [`../rust/`](../rust) (maintained, recommended) and the Node edition in [`../ts-nodejs/`](../ts-nodejs)
- User-facing docs: [`../README.md`](../README.md) / [`../README_CN.md`](../README_CN.md)
- This edition's implementation deltas are registered in [`../docs/SPEC.md`](../docs/SPEC.md) chapter 22 — its Bun entries are a historical record
